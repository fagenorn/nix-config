## Why Codex failed (all fixed in nix-config e4d9bf3, deployed 2026-08-09)

1. `codex-companion` was never a command on PATH → exit 127. Now a wrapper bin.
2. Bridge ran one foreground Bash call: harness cap 600 s < the 840 s budget the
   runtime was asked for → guaranteed SIGTERM on any real review (real reviews here
   ran >10 min). Bridge (plugin patch p3) now launches via background Bash.
3. Missing binary was converted into a ~10-min timeout instead of a sub-second
   capability fallback. Pre-flight `command -v` added on both caller and bridge.
4. Runtime keyed job state to the caller's cwd (orchestrator repo, not the
   worktree) and killed jobs orphaned at status=running. Bridge now cds to a
   `WORKTREE_ROOT:` first line.
5. installed_plugins.json pointed at a GC'd store path (p1) while the marketplace
   served p2 → stale/flaky agent-def resolution. Idempotent activation repair added.
6. Skill contradiction: codex-collaboration said `general-purpose` fallback,
   from-issue Phase 5 said `reviewer`. Reconciled to `reviewer`.

**Session-snapshot rule (operational):** plugin agent definitions are resolved
from the session's snapshot at session start; subagents inherit it. Skill text
refreshes per invocation, plugin agent defs do not — #806 ran the old bridge
4 h after the fix deployed. Plugin-def changes need a fresh session.

**Post-fix validation:** direct runtime smoke test (background Bash, fresh
isolated thread) returned a valid three-section result — every layer below the
bridge verified. The p3 bridge runs first in the next fresh session.

## Open design inputs for C4+G2

- **decision-check has never fired and can't**: `codex.decisionReview` defaults
  off; ~12 high-stakes auto-resolved decisions per run (incl. removing a public
  enum member) get zero cross-check. Decide: enable, redesign, or delete.
- **The native fallback covers one axis only under budget**: #1218's fallback
  self-reported it could not read spec/ADRs/context map/standards — all findings
  came from plan-internal consistency + live code; the doc-conformance axis went
  uncovered. Direct motivation for the two-axis split (G2).
- **Codex's value looks real but unproven**: #1218's truncated review was
  converging on the top Blocking finding. Both agents' judgment: fix the leg
  (done), don't drop the slot; C4's question is "can Codex return inside its
  budget", not "is a second reviewer worth having".
- **Ship-phase CI wait is the flakiest rung**: ~59-min suite vs an 8×5-min
  documented ceiling; #1218 needed 3 CI attempts with no code change (runner
  Nix-store corruption, testhost crash — integration-tests flaky on dev itself);
  `gh pr checks --watch` reported pending after green. Escalate on
  no-step-progress, not wall-clock.
- **Report-delivery reliability**: 1 of 5 agents (#806) never delivered its
  final report despite two nudges; grandchild implementers repeatedly tried to
  SendMessage the literal agent-type name `general-purpose` (2/2 pipelines) —
  sdd's reviewer hand-off addressing needs fixing alongside any ladder change.
- **Machine contention**: parallel worktrees starve each other's full
  `dotnet test Nodo.slnx` runs (issue-1212's whole-project verify killed).
