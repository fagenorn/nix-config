**Durability: intentionally temporary.** This is working audit evidence for the month retrospective. It does not assert a bill, cost, or price.

## Scope and reproducibility

The retained snapshot was inspected 2026-09-19. To exclude live audit
threads, this report uses the 31 completed UTC dates from 2026-08-19 00:00
through 2026-09-19 00:00. Evidence is local read-only Claude JSONL under
/Users/anis/.claude/projects, Codex rollout JSONL under
/Users/anis/.codex/sessions, and Codex SQLite threads and thread_spawn_edges
in /Users/anis/.codex/state_5.sqlite.

The reproducible streaming parser is
/private/tmp/harness-audit-20260919/audit.py. It reads Codex session metadata
before applying the event-time filter, opens SQLite with mode=ro, attributes
Claude from its project-directory slug and Codex from metadata cwd, and retains
source line numbers. The exact event-window file inventory is
/private/tmp/harness-audit-20260919/window-files.txt, generated by a timestamp
query; the event-level totals filter usage_events.csv by timestamp rather than
discarding a session that later crossed the cutoff. Claude children are direct
subagents directory relationships; Codex children are SQLite spawn edges.

Claude assistant messages were deduplicated by message ID within each file:
274,828 raw usage-bearing records became 129,854 unique records, suppressing
144,974 replay/stream duplicates. A fleet check then found 187 message IDs
shared across files (252 excess copies; at most five copies). This is a
record-count duplication observation, not a token-weighted overcount estimate.
Codex has 52,949 token_usage_record events, 52,949 distinct
response IDs, and no cross-file response-ID repeat. Codex totals sum only each
record's usage. They never sum turn_token_usage or thread_token_usage, which
are cumulative snapshots and would overcount.

## Efficiency implications and limits

- Fan-out is an inspection area: 94.3% Claude and 53.4% Codex sessions are
  children. It does not establish a causal efficiency ranking, but supports
  qualitative review of controller/child handoff and replay.
- The 445 explicit Codex compactions record context rebuilding: Nodo
  227, Argus 135, Arcwave 37, nix-config 23, other 23. Claude's different
  context-management representation means “not comparable” is not zero.
- Tool failure and repeated-read counts are intentionally omitted. A text
  match for error in a tool output is contaminated by successful tools reading
  source/log text, and tool calls are attempts rather than confirmed dispatches.
  A credible follow-up needs per-version structured result-status schemas.
- Local history omits provider accounting/pricing, deleted or rotated sessions,
  remote retries, and usage lacking a token record. The major known hazards
  are Claude stream duplicates and Codex legacy cumulative/replay counters;
  this method handles the former, avoids cumulative modern fields, and does
  not merge legacy and modern totals.
- Directory date and session timestamp disagree in a few Codex files. Timestamp
  controls the window. Excluding all live Sep 19 UTC data is intentionally
  conservative, so this is not a complete calendar-month claim.
