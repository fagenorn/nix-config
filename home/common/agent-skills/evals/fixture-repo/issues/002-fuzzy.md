# Issue 2 — make tinytask work better for how I actually work

Been using this for a few weeks and it's not really keeping up. The list gets long and
the important stuff sinks to the bottom, so I end up scrolling past the things I should
be doing. Would be good if it were smarter about that.

Some thoughts, not necessarily all of them:

- Some tasks matter more than others. There should be some notion of importance, maybe a
  score, maybe just an ordering. Whatever feels natural.
- Recent things should probably surface. Or maybe old things should, since they've been
  sitting there? Depends on the task really.
- The states are too rigid. Sometimes something is half done.
- It'd be nice if it worked across my laptop and my desktop.
- Maybe some kind of grouping? Projects, or contexts, or tags — I don't have a strong
  opinion on which.

Basically I want it to feel less like a text file and more like something that helps me
decide what to do next. Use your judgement on the details, you know this codebase better
than I do at this point.
