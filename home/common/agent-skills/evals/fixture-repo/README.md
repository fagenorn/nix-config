# tinytask

A very small backlog kept in a single JSON file. Standard library only.

```sh
python3 -m tinytask add "write the spec"
python3 -m tinytask list
python3 -m tinytask done 1
python3 -m tinytask list --all
```

Run the tests from the repo root:

```sh
python3 -m unittest discover
```

Start with `docs/README.md` — it routes to the context map, the area glossaries and their
decision records, and the coding standards.
