# Wayfind — the traps behind the disciplines

- **Gists stay one line.** A gist decides whether to open the ticket; it never
  stands in for it. A Decisions-so-far gist holds the operative values a later
  session would otherwise re-derive; a research gist holds the conclusion the
  decision turned on, never a findings summary. A longer gist spares no ticket
  read, and every session pays for it again.
- **Compress in the same session, from a fresh read.** A follow-up pays the
  whole context again to learn what to cut, and rewriting from the copy in
  context drops lines a concurrent session appended meanwhile.
- **Never paste a resolution into another ticket.** The copy goes stale when
  the source ticket changes, and it teaches the next session that tickets are
  stores, so it opens a dozen looking for what else was pasted.
- **One sitting per ticket.** A resumed session pays for the whole context
  twice. Parked state in the ticket is what lets the next sitting resume
  without the transcript.
- **Block natively.** The tracker's own UI then shows a human what is takeable
  without opening the map; only a tracker without native blocking falls back
  to a body convention.
