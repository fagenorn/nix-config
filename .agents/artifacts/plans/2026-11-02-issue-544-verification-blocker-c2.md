# Shared Verification Blocker c2 Implementation Plan

> **For agentic workers:** execute this plan with the `sdd` skill — one implementer
> per task, reviewed between tasks. Steps use `- [ ]` checkboxes.

**Goal:** An owner can suspend an attempt on a qualifying verification failure: equal failures in one run share one closed record in a schema-11 ledger, older ledgers migrate strictly, an older helper refuses the new ledger without writing, and nothing resumes a parked attempt before c3.

**Architecture:** Task 1 adds the ledger rules to the pure module `agent_tools.verification_blocker` (`park`, `validate_blockers`, `upgrade_ten`; D2–D5, D9). Task 2 moves the ledger to schema 11: the store composes the 10 → 11 step, `workflow-state` validates the new members, every fixture follows, and the older-helper refusal is proved (D3, D5, D9, D13). Task 3 adds the `verification` cause and its class, `suspend --verification-input`, the shared `suspended` reply, the parked lane and the wire cause (D6–D8, D10, D11).

**Tech stack:** Python 3 standard library (`copy`, `json`, `re`, `unittest`), Git, Just, Nix.

Spec: `.agents/artifacts/specs/2026-11-02-issue-544-verification-blocker-c2-design.md`; a bare "Dn" cites its `## Decision ledger`. Issue: https://github.com/fagenorn/nix-config/issues/544 (boundary c2 of issue 228). c1's rows are "issue 543 Dn".

## Decisions

The plan rests on the spec's D1–D13. Planning appends D14 (the policy's `reply_parked` keyword, which only `direct-owner` passes), D15 (one 10 → 11 step in the store, taken before a ≤ 7 ledger's run is minted) D16 (the in-process wire pin and the base helper's positive control) and D17 (the pointer's id shape enforced by R5, not by a second pattern). Standards review appends D18 (a `verification` cause refused below schema 11, before any mint), D19 (the pointer rule's public refusal tests) and D20 (one-line refusals with escaped keys and pointers).
