# Shared Verification Blocker c3 Implementation Plan

> **For agentic workers:** execute this plan with the `sdd` skill — one implementer
> per task, reviewed between tasks. Steps use `- [ ]` checkboxes.

**Goal:** A parked attempt is released by an observation: control interface 4 and the direct-owner request interface 3 carry `verification` observations, a changed selected value resolves the open blocker before any resuming reply, the same attempt resumes through the unchanged lanes, and the interface-3 bootstrap lists every awaited open blocker.

**Architecture:** Task 1 adds the pure rules to `agent_tools.verification_blocker` (`requirement`, `validate_observations`, `resolve`) and `blocker_resolved` to `resume_permitted` (D2, D4, D5). Task 2 moves control to interface 4: strict loading, resolution inside the sweep before any analysis, the resolved lane, the summary requirement, the validator, `orchestrate-control`, the doc digits and every control fixture and base generation (D3, D6, D8, D9, D11, D13, D16, D18). Task 3 moves the bootstrap to interface 3 (D6, D9). Task 4 moves the direct-owner request to interface 3 with its gate, the `new_run` line, the catalogue entry, the observe slot and acquire-direct's block (D7, D9, D10, D11, D17).

**Tech stack:** Python 3 standard library (`copy`, `json`, `unittest`), Git, Just, Nix.

Spec: `.agents/artifacts/specs/2026-11-02-issue-545-verification-blocker-c3-design.md`; a bare "Dn" cites its `## Decision ledger`. Issue: https://github.com/fagenorn/nix-config/issues/545 (boundary c3 of issue 228). c1's rows are "issue 543 Dn", c2's "issue 544 Dn".
