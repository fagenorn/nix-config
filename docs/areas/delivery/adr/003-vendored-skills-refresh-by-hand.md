# ADR-delivery-003 — Vendored skills are refreshed by hand against a pinned upstream

A skill under `skills/` may adapt an upstream skill, and its adaptations are made by hand, so a refresh is a manual comparison against a newer revision: the recorded adaptations are re-applied and the pin is moved, and the upstream URL, pinned revision, inspection date and every departure from upstream live in the skill's own `LICENSE`, above the unmodified upstream notice. A flake input with build-time synchronisation was rejected because an automatic refresh would silently lose the adaptations; the price is that a refresh costs a person's attention and an upstream fix waits for one, while the contract suite in `home/common/agent-skills/tests/` pins each adaptation so a careless refresh fails a test.
