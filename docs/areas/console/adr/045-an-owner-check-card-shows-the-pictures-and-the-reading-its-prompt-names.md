# ADR-console-045 — An owner check card shows the pictures and the reading its prompt names

Context: a manual check's prompt names PNG files by path, which the page cannot open (#1112). Decision: the console copies the named PNGs into the picture store, only from the project root or the configured screenshot folders, by an anchored walk that follows no symlink. The owner check card shows them, with one line for each file not found, and shows a `Reading:` line as its own line; how the page captions a thumbnail and where the reading sits are ADR-console-047's. Rejected: a route serving host paths, and following a symlink under an allowed root.
