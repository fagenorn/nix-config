# ADR-console-076 — The owner's port answers only the owner's own processes

Context: on the shared Mac any local account could load the owner's page, read its token and write (#1294). Decision: the owner's port admits a connection only when the processes holding its client end (read by `lsof` on macOS, `/proc` on Linux) include one of the owner's uid and none of another, checked before the `Host` check and before any body, and refusing whenever the lookup does not complete; an administrator, root and any relay the owner runs stay out of reach. Rejected: the page token alone, parsing the `net.inet.tcp.pcblist_n` sysctl, and a Unix socket for the owner, which a browser through an SSH forward cannot reach.
