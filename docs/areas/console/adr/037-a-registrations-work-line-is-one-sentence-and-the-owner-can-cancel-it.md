# ADR-console-037 — A registration's Work line is one sentence, a failure's way out is an option, and the owner can cancel a registration

Context: the Work column still drew lines and a Close that only hid the box, and a failed apply left a copy for an agent to remove (#1088). Decision: a registration's Work line is one sentence, and Close is gone. A failure's next step is at most two sentences in its card's option words. The console removes a failed apply's kept copy only through the adoption tool's acknowledged cleanup (`apply --discard-retained`, `discard`), and the owner can cancel a registration on `POST /api/register-cancel`; its refusal while a failed commit's card is unseen is ADR-console-071's, and the live check's restoring cancel ADR-console-084's. Rejected: `git worktree prune`, which drops other worktrees' admin entries, and leaving the copy for an agent. Amended by #1095: signing is a platform constant (ADR-project-contract-013 D1), so a signing failure's card offers no way to turn it off. On a drafted contract the one way out is a signing key on this computer; on a committed schema-2 contract that asks for signed commits the note also says that setting lives in the repository, and the console edits no file there. Rejected: a `Turn signing off` option that changes the draft, which a schema-3 draft may not author.
