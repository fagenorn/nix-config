# ADR-console-079 — Serve needs a tailnet access rule for TCP 443, and the console tells this host's own requests apart

Context: other devices timed out because the tailnet's rules allowed only TCP 22 and 8000 to this host, and a self-probe read like a visit (#1320). Decision: Serve stays on 443 and needs a tailnet access rule for TCP 443 from the listed colleagues' devices, set by the tailnet admin and never kept in the repository; one `X-Forwarded-For` matching `Self.TailscaleIPs` marks a request from this host, anything unreadable is unknown and never another device, and only that result is kept, never an address; the Sharing panel says whether another device has arrived, and the held check counts only another device. Rejected: moving Serve to 8000, which the shared oMLX server holds, a self-probe as proof, and keeping the client's address.
