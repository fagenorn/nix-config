# ADR-console-063 — A bypass proof runs on a throwaway repository it registers and removes

Context: a bypass manager relies on the guard alone, which only attempting each forbidden action for real proves (#1152). Decision: `bypass-proof github`, run only by the owner from a terminal (an agent session is refused), creates a private throwaway repository, registers it under a `bypass-proof/` id through the fleet registry's transaction, the registry's second writer, which can remove no other id, records each refusal and every teardown step in a 0600 record, and always unregisters, recompiles and deletes. Rejected: a full adoption of the throwaway, and a proof against a repository whose loss costs something.
