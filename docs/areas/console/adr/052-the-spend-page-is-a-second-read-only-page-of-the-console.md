# ADR-console-052 — The Spend page is a second, read-only page of the console

Context: the spend ADR-console-049 reads had no page, and the desk page must stay about whether the owner is needed (#1135, #1136). Decision: `GET /spend` serves a second page from memory on loopback with no token and no write, reading only `/api/stream`: Today and 7 or 30 days in tokens and estimated `~$` dollars, a daily trend and breakdowns by project, sprint, phase, account and aspect. The desk links it once from its top bar, and a running sprint, a delivery run line and a finished sprint show one quiet figure line linking to `/spend#sprint=<id>` or `#run=<id>`, which opens that item's 30-day phase breakdown. Rejected: figures on the desk page, and a figure link inside a fold's summary, which nests a link in the control that opens the fold.
