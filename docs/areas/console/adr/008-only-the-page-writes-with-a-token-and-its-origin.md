# ADR-console-008 — Only the page writes, with a per-install token and the console's own origin

Context: the hook route (ADR-console-004) answers nothing and carries no token, but the page has to write (that the owner looked, answers, goals), and a write that changes what the owner is told must not come from another local process or from a foreign web page (#838 item 7). Decision: a page write is a member of `PAGE_WRITES` in `agent_tools.console.service`, and every member passes one guard that runs after the loopback `Host` check and before any body is read. The guard admits a write only when exactly one `Origin` equals the console's own origin and exactly one `X-Console-Token` equals the per-install token, compared in constant time. Each route bounds its own body. The guest door uses the same guard shape, with the guest token and its tailnet origin (ADR-console-077). Rejected: loopback trust alone, because any local process or foreign page could then write; and a token without the origin check.
