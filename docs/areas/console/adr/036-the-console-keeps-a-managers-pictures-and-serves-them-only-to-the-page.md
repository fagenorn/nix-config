# ADR-console-036 — The console keeps a manager's pictures and serves them only to the page

Context: a picture is bytes from a local process, and the console must not keep arbitrary files, grow without bound or hand a stranger's bytes to a browser (#1089). Decision: the console keeps a body only after a PNG header check, at most 2 MiB. It stores it by its SHA-256 in a `0700` directory as `0600` files, and takes it only as a manager write under the sprint's secret with any `Origin` refused. It serves it only to the page, with the page's token, and sweeps it a day after no row references it (ADR-console-001). Owner check pictures are ADR-console-045's. Rejected: serving a host path or keeping any file a process sends, and an unbounded store.
