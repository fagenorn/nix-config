# ADR-console-058 — A question about a project is answered by a read-only session

Context: the owner could not ask a plain question about a registered project without starting a sprint, and a session that can write or reach a tracker would turn a question into a delivery (#1176). Decision: `POST /api/project-question`, a page write, runs one `claude-account run -p --model sonnet` session in the project's root under the profile the console chose, failing closed: no user, project or local settings, `dontAsk`, a deny list of every write tool, web tool, Agent and lifecycle verb, and a hook with `onFailure` `block` that admits only reads and the contract's read-only commands declared to run from the root; a 300 s cap; an asked and an answered row in the log and nothing on the tracker. Rejected: a session only told by its prompt to read, and a sprint for a question.
