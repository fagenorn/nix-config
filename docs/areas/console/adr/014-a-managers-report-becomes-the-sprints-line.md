# ADR-console-014 — A manager's report becomes the sprint's line

Context: the owner reads one plain line per sprint (#833, #837). Decision: the line comes from the manager's fixed-shape report, sent with the sprint's secret and kept indefinitely, with the run journals filling in between reports. A sprint is quiet, never stalled, without a positive signal. Rejected: issue numbers, branches and session names on the line's face, because the owner reads one plain line; they stay behind the report fold.
