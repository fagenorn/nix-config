# ADR-console-077 — The guest door on eleven-m5 is a Unix socket only Serve and the owner can open

Context: the console moved to eleven-m5, a shared Mac where `tailscaled` runs as root and other accounts and CI runner users run processes, so the loopback guest port of ADR-console-066 was reachable by any local account (#1298, #1299). Decision: the guest door is a Unix socket, mode 0600, in a mode-0700 folder of the owner's user, and Serve proxies to it (`sudo tailscale serve --bg --https=443 unix:<socket-path>`); before reading a connection the console refuses a peer other than root or the owner, and a folder or file that is not the owner's or is wider than 0700 or 0600; a guest request carries exactly one `Host` of `localhost`, exactly one `X-Forwarded-Host` equal to the tailnet name with no port, and exactly one login header naming a listed colleague (`<colleague-login>`); an administrator with sudo stays out of reach. Rejected: the loopback TCP guest port, the peer check alone with a reachable socket, and Funnel.
