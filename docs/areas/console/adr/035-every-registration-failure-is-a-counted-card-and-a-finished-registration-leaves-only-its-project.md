# ADR-console-035 — Every registration failure is a counted card, and a finished registration leaves only its project

Context: failures were uncounted Work-column paragraphs that named commands, paths and hashes (#1085). Decision: every registration failure is one counted question card with `Try again` and `Not now` on the existing `POST /api/register-confirm`. While a card names the root, the Work column holds the one needs-you line, with only the unread-remote sentence of ADR-console-070 beside it, and a registered root leaves only its project. No command, plan id, hash or absolute path of the console's own reaches the page (`just switch` excepted, ADR-console-037); a failed commit's git lines, sanitized and held to the page pattern, are ADR-console-071's. Rejected: a result paragraph in the Work column, and a new route for the card.
