# ADR-console-018 — A sprint ends with a closing report or the owner's stop

Context: a finished sprint never folded away, and a withdrawal left an idle session spending quota. Decision: a sprint ends by the manager's closing report, which must account for every issue, or by the owner's stop, which is one stored message with a ten-minute timeout. Either way the manager's session is stopped once, through the shared stop, and an ended sprint folds into Finished sprints a day later. Rejected: withdrawal as the only way to end a sprint.
