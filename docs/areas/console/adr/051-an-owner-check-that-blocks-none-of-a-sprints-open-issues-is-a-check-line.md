# ADR-console-051 — An owner check that blocks none of a sprint's open issues is a check line, not waiting on you

Context: an owner check that blocks none of the sprint's work read as waiting on the owner while the manager built (#1111). Decision: an owner check whose tracker blocking edge shares no number with the sprint's open issues is one "Your check" line in the sprint block, still one inbox item. A missing or malformed blocking list counts as blocking. Its page change was held for the owner's pictures (ADR-console-038). Rejected: every check that names an issue reading as waiting, and reading unknown as not blocking.
