# ADR-console-028 — The owner registers a project from the page

Context: registering a project needed `adopt-project plan` and `verify --register` in a terminal (#1052, #1055). Decision: the page's Register project control, a page write under ADR-console-008, has the console run the adoption tools as bounded children off the request path, on Linux and macOS, and show their result in plain lines. A merged adoption's project is registered by the console itself once origin's integration branch carries it, and a failed one is a counted Try again card (ADR-console-035). The console never writes the registry. Where registration runs is ADR-console-081's, the comparison with the remote before a fresh plan ADR-console-070's, and which registration the page shows ADR-console-084's. Rejected: a second adoption implementation in the console, and running the tools on the request path.
