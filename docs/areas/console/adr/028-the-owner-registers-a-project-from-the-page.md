# ADR-console-028 — The owner registers a project from the page

Context: registering a project needed `adopt-project plan` and `verify --register` in a terminal (#1052, #1055). Decision: the page's Register project control, a page write under ADR-console-008, has the console run the adoption tools as bounded children off the request path and show their result in plain lines. A merged adoption's project is registered by the console itself once origin's integration branch carries it, and a failed one is a counted Try again card (ADR-console-035). The console never writes the registry. Registration, its plan answers, adoption approval and the merged-adoption registration run on Linux and macOS, each child in its own session, and the console's close stops each child's group and waits for every accepted run before the log closes (#1330). The comparison with the remote before a fresh plan is ADR-console-070's, and which registration the page shows is ADR-console-084's. Rejected: a second adoption implementation in the console, and running the tools on the request path.
