# ADR-console-078 — The guest door takes its tailnet name from this host's Tailscale client

Context: the log rescued from a gone host named another tailnet, so every colleague was refused (#1305). Decision: the tailnet name is `Self.DNSName` of this host's `tailscale status --json`, trailing dot removed and lowercased, kept only in the `<host>.<tailnet>.ts.net` form and read each minute into memory only; admission, the reading and the origin all use it; an unread name refuses every guest request (`name_unread`); the access list only turns sharing on or off. Rejected: a typed name with a warning, the keys of the Serve config, and the machine's hostname.
