# ADR-console-021 — A manager's session runs with the background isolation guard off and its own permission hook

Context: the first end-to-end sprint stopped at its first delivery, because the background isolation guard refused writes into the delivery worktree's git directory, and a permission prompt then waited in a terminal nobody watches. Decision: the settings file written before every launch and wake turns `worktree.bgIsolation` off, since a manager writes no code and every delivery makes its own worktree. The file also carries the manager's own `PermissionRequest` hook, so no prompt waits in its terminal and the answer holds while the console is down. What that hook answers is ADR-console-100's. Rejected: keeping the guard on, under which a manager cannot run a delivery; and answering prompts from a console route, which fails while the console is down.
