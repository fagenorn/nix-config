# ADR-console-032 — A tracker write rides out a short network drop and fails in plain words

Context: a short network drop made the page's tracker write (ADR-console-010, ADR-console-012) fail with a raw transport error and no way forward but to choose again (#1075). Decision: the console retries only a transient failure (a timeout, a connection failure or a 5xx) at 1, 2, 4, 8 and 10 seconds within 30 seconds. Each attempt reads the tracker again, so an answer that already landed is left alone. A failure it cannot mend is shown in plain words with no status code or exception type, and a note is tried once. Rejected: retrying a note, which could post it twice, and retrying a refusal or a 4xx.
