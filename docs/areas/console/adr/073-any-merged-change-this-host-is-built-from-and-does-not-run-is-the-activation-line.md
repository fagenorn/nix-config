# ADR-console-073 — Any merged change this host is built from and does not run is the activation line

Context: the activation line watched only console files, so a merged change to a skill, a patch or a Nix module left the host inactive while the line said all was active (#1258). Decision: console files keep their blob comparison; every other path is compared from the host's configuration revision to origin's tip, counting every path but a named list no host reads; the line says console, agent tooling or host configuration; a failed read keeps the line, and a failed run stays retryable for a day. Rejected: a manifest of every file's blob in the console's build, which would restart it on every commit; the system revision alone; and an inclusion list a new directory would escape.
