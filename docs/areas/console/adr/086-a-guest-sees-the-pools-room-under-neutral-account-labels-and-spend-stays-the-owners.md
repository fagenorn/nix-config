# ADR-console-086 — A guest sees the pool's room under neutral account labels, and spend stays the owner's

Context: a guest could not see the pool's room, and a profile name or address identifies a person (#1341). Decision: the guest view carries a `pool` with its state and per-account rows under `Account <n>`; a running sprint names its account's label; no profile name, address, organisation or proxy id reaches a guest; numbers belong to accounts and persist in `account-numbers.json`; spend stays null, the owner's. Rejected: numbering by name order on each read, numbers per profile, numbers in memory only, and showing spend.
