# ADR-console-060 — A manager's permission mode is chosen per project

Context: in `auto` the client's classifier stopped a manager at steps nobody watching could answer, while the guard already refuses what production rules forbid (#1151). Decision: the console writes a manager's `permissions.defaultMode` into the manager's own settings file, read again on every launch and wake and logged with its reason: `bypassPermissions` only where the contract declares no production or the guard's compiled policy holds its production rules, else `auto`; the owner's own sessions keep `auto`. Since #1228 it never chooses bypass until a bypass manager can be woken, because the client holds another session's message for a bypassing receiver. Rejected: one global mode for every session, and bypass with production rules the guard does not hold.
