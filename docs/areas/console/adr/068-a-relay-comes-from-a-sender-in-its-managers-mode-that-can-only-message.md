# ADR-console-068 — A relay comes from a sender in its manager's mode that can only message

Context: the client delivers a peer message only between sessions of one permission class, so a bypass manager was deaf to the console's prompting relay (#1228, #1230). Decision: a relay carries `--permission-mode bypassPermissions` exactly when its sprint's newest logged mode is bypass, and every relay can only message (`--tools SendMessage,ListAgents`, no MCP server); wakes and revives are unchanged. Rejected: `crossSessionInbound: accept` on the manager, which accepts every local sender, and a sender that always bypasses, which deafens every `auto` manager.
