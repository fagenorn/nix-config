# ADR-console-031 — A repository with no contract is registered with a drafted contract

Context: a repository with no contract could never reach a ready plan (#1067). Decision: the console drafts a project-schema-3 contract from the remote and the tracked files. It asks as cards only the authored values it cannot read, and shows the derived facts computed from the bytes the adoption writes; the draft proposes no commit environment, which is ADR-console-082's. It hands the draft to `adopt-project plan --contract-draft`. Before apply, the one write into the checkout is the owner's `Update it`, which is ADR-console-070's. Rejected: silently defaulting a policy value, and asking the owner to write the contract in a terminal.
