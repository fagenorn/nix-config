# ADR-console-084 — A registration whose project is unregistered gives way to the registration it replaced

Context: the live check's throwaway rows replaced the owner's shown registration and stayed after the check removed its project (#1334). Decision: `register.fold` keeps the registrations shown before, one per root, and a `project.unregistered` of the shown root folds back to the previous one; the live check runs only while no open registration shows, sends `unless_open`, and undoes its own row with a restoring Cancel (`restore`); the owner's page sends neither. Rejected: one level of `before`, matching rootless rows by project id (two checkouts can share one), and a Cancel that always reverts, which would change the owner's Cancel (ADR-console-037).
