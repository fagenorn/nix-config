# ADR-console-059 — A project question is spent under its project, threaded in the log and can fill a goal

Context: the Spend page counted a question's session as an outside-sprint session (#1180). Decision: the console gives every question a fresh UUID, passes it as `--session-id` and records it in the asked row, so the question's transcripts are the questions aspect under its project; threads are rows of the console's log and Make it a goal fills the goal box with the question and the answer's summary, stating nothing. Rejected: naming the session with `--name`, whose record for a `-p` run is unconfirmed, and matching the prompt's lead in the transcript, which breaks when the lead changes.
