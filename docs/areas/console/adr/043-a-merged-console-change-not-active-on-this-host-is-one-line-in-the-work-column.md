# ADR-console-043 — A merged console change not active on this host is one line in the Work column

Context: the console ran stale after a merge, and nothing on the page said so (#1114). Decision: the console compares the git blob ids of its running package's files, and of the modules they import, with origin's integration branch as last fetched, and that comparison decides the console wording; every other path the host is built from is compared from the host's configuration revision, and which paths count and the line's words are ADR-console-073's. It never fetches. A difference is one uncounted line at the head of the Work column whose Activate is ADR-system-004's, held in memory, a scoped exception to ADR-console-001, and a failed read keeps the last reading. Rejected: the system revision alone, which changes on every commit, documentation included.
