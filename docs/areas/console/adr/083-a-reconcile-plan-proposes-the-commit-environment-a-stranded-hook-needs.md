# ADR-console-083 — A reconcile plan proposes the commit environment a stranded hook needs

Context: an adopted checkout whose commit hook execs a runner only the development shell provides planned `reconcile` with no environment and failed at the adoption commit (`exec: prek: not found`) (#1333); the drafted project-schema-3 contract proposes no commit environment, its commits always running in the platform's devenv command (#1268, #1485). Decision: a fresh registration of a checkout with a contract proposes `devenv shell --` as a one-field draft when `HEAD` holds a root `devenv.nix` and an installed commit hook is stranded; an installed commit hook is an executable `pre-commit`, `prepare-commit-msg` or `commit-msg` in the repository's own hooks directory; stranded means it execs a runner the console's own `PATH` cannot resolve, and reading runs no hook; `none` plans as before, and a contract that already names one keeps it (ADR-project-contract-008). Rejected: counting an untracked `devenv.nix`, `post-commit` or a global `core.hooksPath`, and planning the reconcile with no environment.
