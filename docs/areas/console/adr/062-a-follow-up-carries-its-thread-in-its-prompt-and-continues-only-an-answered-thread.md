# ADR-console-062 — A follow-up carries its thread in its prompt and continues only an answered thread

Context: a follow-up must continue its question's thread (#1178). Decision: a follow-up names its `thread_id`, is admitted only for a thread of that project whose last question is answered, carries the earlier turns in its prompt under a first question's rules, and is refused past `MAX_THREAD_BYTES`, below Linux's single-argument limit; admission reads the retained log as a restart would. Rejected: `--resume` of the earlier session, which ties a follow-up to a profile and a store the console does not own; continuing a failed or timed-out thread; and dropping the oldest turns to fit.
