# ADR-console-074 — The console records a look approval itself when the owner approves a look card

Context: the owner approved a look card and the approval never reached the issue, because the safety check refused the agent session's post (#1260). Decision: the console posts the owner's `agent:look` approval itself, only for the card's approving option picked with no words, reading the pull request's head before the post and again after it and ending a marker whose head moved; `look.recorded` is a kept kind (schema 11), the manager hears the approval only once it is posted, a failed post keeps Retry, and the marker names its pictures' digest (#1566). Rejected: the agent session posting the owner's approval, and recording an answer with words as an approval.
