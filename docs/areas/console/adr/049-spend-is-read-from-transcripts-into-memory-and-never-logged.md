# ADR-console-049 — Spend is read from transcripts into memory and never logged

Context: the owner could not see where the host's tokens and dollars go, and the transcripts hold every message's usage (5 GB over 30 days) (#1134). Decision: spend is read incrementally from the transcripts into memory. Each message id counts once, attribution happens when the view is derived, dollars are estimates at list prices, and none of it is logged. An engine agent session, which has no journal, is attributed by its run's ledger: the run whose events name its session id, that step's stage, and the sprint of the session that started the run, while the ledger's own spend figures are never read, and a run the engine has swept keeps that attribution only in a console that read it before the sweep. How a project question's session is spent is ADR-console-059's, and the read a question runs before the first poll ADR-console-089's. Rejected: a row per message in the event log (ADR-console-001), which would bury the rows that matter and double what the transcripts hold.
