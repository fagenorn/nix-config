# ADR-console-049 — Spend is read from transcripts into memory and never logged

Context: the owner could not see where the host's tokens and dollars go, and the transcripts hold every message's usage (5 GB over 30 days) (#1134). Decision: spend is read incrementally from the transcripts into memory. Each message id counts once, attribution happens when the view is derived, dollars are estimates at list prices, and none of it is logged. How a project question's session is spent is ADR-console-059's, and the read a question runs before the first poll ADR-console-089's. Rejected: a row per message in the event log (ADR-console-001), which would bury the rows that matter and double what the transcripts hold.
