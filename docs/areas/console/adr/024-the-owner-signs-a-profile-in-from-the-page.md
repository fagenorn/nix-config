# ADR-console-024 — The owner signs a profile in and adds an account from the page

Context: a signed-out profile's remedy was a terminal command, and a new profile could be made only with `claude-account add` in a terminal (#842). Decision: the page signs a profile in by running the client's own `auth login` under it, with no terminal, the proxy off and no inherited key. `BROWSER` writes the link into a FIFO that the console reads. The link reaches only a guarded page write (ADR-console-008) and never a row, a view or a log line. The code is written to the client's standard input, and there is one run per profile, ending at exit, on Cancel or after 600 s. Add account runs `claude-account add <name>` and goes straight into that sign-in, so a profile added on the page is the one a terminal makes (ADR-hosts-005). The client's status read (ADR-console-022) alone says signed in. Rejected: a terminal command for the owner to copy, and the console making profile directories itself.
