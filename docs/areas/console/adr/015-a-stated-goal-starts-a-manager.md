# ADR-console-015 — A stated goal starts a manager in its own scope

Context: a sprint has one manager, which the console starts (#835). `claude --bg` detaches one supervisor per configuration directory, and a supervisor started inside a unit dies with it (#831). Decision: the console starts the manager as a background session under the profile it chooses (ADR-console-023), in its own `systemd-run --user --scope` on Linux and in its own session on macOS. The sprint's id and secret are in a per-sprint 0600 settings file passed with `--settings`. The manager's contract is package data printed by `sprint contract`, outside the instruction corpus. A failed first launch with no brief is one counted card whose reason is one of a closed set of plain words, with Retry, and whose ball is the owner's; the client's raw words stay in the log and the journal (#1182). Rejected: the launching client's environment for the secret, which a running supervisor may not see; a launch inside the console's unit, which dies with it; and a line inside the sprint block in the client's raw words.
