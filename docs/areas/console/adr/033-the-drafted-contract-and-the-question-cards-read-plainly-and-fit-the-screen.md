# ADR-console-033 — The drafted contract and the question cards read plainly and fit the screen

Context: the first screenshots showed some 25 drafted values in internal terms and cards that disagreed (#1079). Decision: `contract_draft.py` owns every drafted-value word and the page shows them verbatim. The three main fields (the integration branch and the lint and test commands) and the five fact lines show, and the rest fold under one counted line; the commit environment is no drafted line (ADR-console-082). A stored draft is read back in the current words through `contract_draft.refresh`, never rewritten. Rejected: the page composing its own words, and rewriting stored rows.
