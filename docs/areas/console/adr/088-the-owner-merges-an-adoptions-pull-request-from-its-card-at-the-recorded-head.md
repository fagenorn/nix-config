# ADR-console-088 — The owner merges an adoption's pull request from its card, at the recorded head

Context: ADR-console-030 left the merge to the owner on the forge, and the card could not say why a pull request was not ready (#1338). Decision: the owner's Merge on the card is one `gh api -X PUT repos/<slug>/pulls/<n>/merge -f sha=<head>` pinned to the recorded head, offered only for a `ready` pull request the console made (`created`, matched forge `id`) whose head and target equal the recorded ones; the route refuses a stale card and records one fresh reading first; `failing` reads every check page. Rejected: a lifecycle-guard rule for the console's pull request, merging on the forge by hand, and reading only the first check-run page.
