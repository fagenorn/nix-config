# ADR-console-054 — A held issue whose only open criterion is an owner review gets an owner check card

Context: a held issue whose only open criteria were owner reviews, with no runner prompt, told the owner nothing (#1091, #1113). Decision: a second, lenient search reads `needs-verification` issues by an OWNER or MEMBER with no live trusted runner prompt and raises one owner check card per unticked `[human]` criterion of the body's first Acceptance criteria section, only when no `[evidence]` or untagged criterion is open and no held verify check names it, and none for a closed or settled issue or a look marker whose approved head merged (#1186, #1211, #1327); Approve reads the issue again and ticks only that box in the body, Not yet posts a note, and both refuse when anything changed. Rejected: waiting for the runner to post a prompt, and asking a criterion the runner asks when its check is due.
