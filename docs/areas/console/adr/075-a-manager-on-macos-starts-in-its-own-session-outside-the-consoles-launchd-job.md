# ADR-console-075 — A manager on macOS starts in its own session outside the console's launchd job

Context: macOS had no launcher, because `systemd-run` is Linux only and launchd ends every process left in a job's group when the job dies, so a manager started as the console's child would die at every restart (#831, #894). Decision: on macOS a manager, its wakes and the account runs start in a session of their own (`start_new_session`), the console's launchd job sets `AbandonProcessGroup`, and the console ends its own stop commands as it closes. Rejected: starting the manager inside the console's process group.
