# ADR-console-003 — The inbox is read from the tracker every two minutes, for active projects only

Context: the inbox lists the owner-action markers of open issues and pull requests, which live on the tracker and nowhere in the console. Decision: the tracker is the source, read every two minutes only for active projects (touched in the last day), with markers deciding and labels filtering, and comments read only from trusted authors. A failed read keeps the last items as stale and never says nothing needs the owner. Rejected: reading every registered project on each poll, because that spends the rate limit on projects nobody touches; and an empty inbox on a failed read, because it would tell the owner nothing waits when the console simply could not look.
