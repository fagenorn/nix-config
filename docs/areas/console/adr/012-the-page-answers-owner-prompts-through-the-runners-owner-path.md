# ADR-console-012 — The page answers owner prompts through the runner's owner path

Context: a held verification waits on an owner prompt on the tracker (ADR-verification-009), and #863 lets the page answer it. Decision: the page answers one item per request through the verification area's single-prompt owner path, which re-reads the live prompt and refuses it when its content changed. Every approval, live or paid, needs the typed confirmation, and the console offers no multi-item action. Rejected: the confirmation only for paid checks, as #863 names, because the stricter bar of #836 is kept; and any bulk answer from the page, because a live approval could then go out behind another item's confirmation.
