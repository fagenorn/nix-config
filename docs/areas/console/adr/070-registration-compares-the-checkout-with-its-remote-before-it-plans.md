# ADR-console-070 — Registration compares the checkout with its remote before it plans

Context: a registration planned from a checkout days behind its remote (#1233). Decision: a fresh registration first lists origin and fetches only its default branch with `adopt_inspection`'s pinned fetch, never moving `HEAD`; a checkout behind gets one card with Update it and Not now; Update fast-forwards only on the default branch with no local change or commit, runs no hook and grants no trust; an unreadable remote registers as before with one sentence saying so. Rejected: an option to plan from the stale checkout anyway, and a second fetch policy in the console.
