# ADR-console-042 — A sprint reads stuck only when nothing it reads has moved

Context: the ball and the state line read movement from different signals, so a working sprint read "may be stuck" (#1109, #1229). Decision: one movement reading feeds the state line, the ball, the "last seen" prefix, the digest and the sprint's run lines, which are ADR-console-069's. A sprint moves when a listed session works or when the latest of the goal, the approval, the report, its runs and the later signals is under fifteen minutes old (ADR-console-005): the waits are ADR-console-050's and ADR-console-061's, session output and a running check ADR-console-057's. A run counts whenever it moved. A failed launch drops the goal's time, and a failed first start's card, line and ball are ADR-console-064's. A held peer message reads "the manager cannot hear the console". Rejected: a signal per surface, and clearing movement at each report.
