# ADR-console-004 — Sessions arrive by hooks and a five-second registry poll

Context: the page must show whether a session waits for the owner. Hooks fire at once, but an interrupt raises none, and SessionStart takes no HTTP hook (#829). Decision: five HTTP hooks post to an append-only hook route that answers an empty 204 and decides nothing. A dash-and-curl SessionStart script handles session start, and a five-second poll of the session registry fills the gaps. Rejected: hooks alone, which miss interrupts and give no list of what runs now; and a Python SessionStart command, whose start alone exceeds the 10 ms a hook may add (#838).
