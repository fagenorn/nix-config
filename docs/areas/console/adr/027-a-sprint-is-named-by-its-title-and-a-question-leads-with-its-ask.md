# ADR-console-027 — A sprint is named by its title and a question leads with its ask

Context: a 1,400-character goal named the sprint everywhere on the first screen, and a manager's question ran to paragraphs, so the owner scrolled to find what was asked (#1031). Decision: the write path refuses an over-limit part before anything is logged: a brief title over 60 characters, an ask over 140, a context over 400 or an option over 80. A sprint is named by its brief's title, falling back to the goal's first sentence, and only the sprint entry carries the goal. Logged rows are cut for display and never refused on read. Rejected: cutting at display only with no write limit, and refusing or rewriting rows already logged.
