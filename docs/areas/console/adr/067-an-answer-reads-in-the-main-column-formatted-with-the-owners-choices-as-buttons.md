# ADR-console-067 — An answer reads in the main column, formatted, with the owner's choices as buttons

Context: the first answer was raw text in the narrow Work column with the question shown twice (#1226). Decision: one thread is read at a time in a panel in the main column; the answer is drawn from DOM nodes for a closed subset (code fences, lists, paragraphs, bold, inline code) and anything else shows as text; the session's question back ends the answer in a call-out whose two to five choices are buttons that post a follow-up. Rejected: the Work column, a markdown library parsing view text into HTML, and raw HTML from the session.
