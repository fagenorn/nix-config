# ADR-console-094 — A manager runs only the merges and reruns the console permits

Context: ADR-console-021 refuses every permission prompt of a manager and the owner's global settings allow `gh pr merge`, so a manager's merge of its green pull requests and a rerun of a failed check waited for the owner, who listed the grant (#1377, #1401). Decision: a manager may run, each alone, its own sprint's merge at its matched head, the failed-job rerun of its own pull requests' required check runs, and the plain `release transaction run` with only its exact flag-value pairs, a grant and not a check because the release command refuses an unapproved candidate (ADR-console-097); abandon and dispose are denied from the parsed words; the grant is a `PreToolUse` and `PostToolUse` hook (`sprint permit`) with no allow rule and no `if` filter, deny rules refuse an `--admin` merge and a release abandon, every verdict is a `permit.judged` row, and it fails closed. Rejected: allow rules or an `if` filter, whose missed spelling falls to the global merge allow, and judging a release's approval from shell text.
