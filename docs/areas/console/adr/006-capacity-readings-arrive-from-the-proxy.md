# ADR-console-006 — Capacity readings arrive from the proxy and are kept per profile

Context: the owner needs each account's capacity, and the cache proxy already sees every response's rate-limit headers (ADR-hosts-007). Decision: readings come from the proxy over an append-only route. The console probes each listed profile every 10 minutes through the proxy, so an idle or exhausted profile still gets a reading, and credits a reading to a profile by the probe's session id first. Rejected: reading the client's credential files, because the console must never read, store or log a credential. The cost is one small request per profile per interval.
