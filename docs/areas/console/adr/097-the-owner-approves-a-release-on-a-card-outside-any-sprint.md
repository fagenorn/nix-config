# ADR-console-097 — The owner approves a release on a card outside any sprint

Context: a permit that judges shell text cannot name every spelling that runs a release, so the owner decided the release command itself refuses a candidate with no approved card (#1401). Decision: the lead posts one release card for a commit and version outside any sprint (`release-card post`, `POST /api/release-card`, which approves nothing); the owner approves or declines it on the page (`POST /api/release-answer`, an owner-only page write, the first answer winning); the release command reads the console's store read-only, and an approval lapses after 90 days. Rejected: a permit check of the release's shell text, and an approval given in chat.
