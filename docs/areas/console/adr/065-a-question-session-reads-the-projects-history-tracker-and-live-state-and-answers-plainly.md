# ADR-console-065 — A question session reads the project's history, tracker and live state and answers plainly

Context: an answer about the last week and production came back in decision-record jargon, because the session could not read git history, and a production read failed outside the project's environment (#1225). Decision: the hook also admits plain git reads with the subcommand as word 1 and no `--output` or `--ext-diff`, and `gh` `pr`, `release`, `issue` and `run` `list` and `view` only with `--repo` pinned to the contract's GitHub tracker right after the verb; Bash is always a tool and each read has a prefix allow rule the hook narrows; a route runs in `devenv shell --` when the root holds a `devenv.nix`; the answer leads with a plain direct answer. Rejected: a hook allow with no allow rule, unconfirmed under `dontAsk`; gh without a repository pin; and a contract member for the environment.
