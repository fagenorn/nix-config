# ADR-console-080 — The sign-in hands out the client's manual link, or names the port to forward

Context: a sign-in started from a browser on another Mac returned to that Mac's `localhost` callback (#1323). Decision: the console reads the client's stdout for its manual link, an `https` link whose `redirect_uri` is not loopback, and prefers it (`manual`); otherwise it hands out the loopback link with its port and `ssh -N -L <port>:localhost:<port> <host>` (`loopback`), otherwise `unknown`; one link only; the output stays in memory, never in a row, a log line or a view. Rejected: rewriting the loopback link's `redirect_uri`, showing both links, and a pseudo-terminal.
