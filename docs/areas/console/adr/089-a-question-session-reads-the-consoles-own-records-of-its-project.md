# ADR-console-089 — A question session reads the console's own records of its project

Context: a project question was answered that nothing records spend, though the console keeps it (ADR-console-049) and its log holds deliveries and activations; handing the session a file in the console's state directory exposes the log, the page token and other questions' records (#1271, #1357). Decision: each accepted question gets one `<question id>.records.json` of only its project's records (spend, deliveries, activations, sprints, held checks), mode 0600 in the 0700 settings directory; the hook refuses every read of the console's state and of the transcript stores except that file and the session's own `tool-results`, judged by filesystem identity; the console runs its spend poll once first when it has no spend view; the prompt gives each section's offset and limit; an answered question's file is kept 90 days for its check; a `request_key` asks a question once. Rejected: a Bash route printing the records, an MCP tool, a console HTTP read, unconfined reads, and one file per section, which would widen the one-file confinement.
