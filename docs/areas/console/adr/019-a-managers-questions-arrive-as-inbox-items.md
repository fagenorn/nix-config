# ADR-console-019 — A manager's questions arrive as inbox items and are answered on the page

Context: a third of what the owner typed answered a manager's questions, each in a separate terminal. Decision: a manager sends one round of two to four option questions with `sprint ask`. The round is kept only in the console's log, one open round at a time unless it is a blocker, and the answer is a message like any other. A manager takes back or replaces its own open question (#1099): the withdrawal is a kept kind, a one-way schema step, so retention never brings the question back, a replacement rides on the replacing round's row so the owner never sees both cards, and an answer to a question taken back is refused. Rejected: questions riding in the brief's asks or a terminal prompt, a copy on the tracker, and asking again beside the stale card.
