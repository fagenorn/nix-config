# ADR-console-001 — The console's truth is an append-only event log kept for 90 days, served on loopback

Context: the owner needs one place that says whether they are needed, fed by hooks, the proxy and managers, and the log must stay bounded without letting a raw connection rewrite history (#838, #861). Decision: every fact is one row of an append-only SQLite log, and rows are never updated. The page's view is derived in memory and rebuilt from the log at start. The service binds `127.0.0.1:27184` only. Rows are deleted only by the retention pass, with one other delete, the owner's removal of a question thread (ADR-console-093); the pass keeps 90 days behind a cutoff that triggers let only move forward. The pass never removes the kept kinds (goals, briefs, reports, messages, questions, notices), whose raw delete the triggers refuse whatever its age. Rejected: a view derived on each read by asking every source, and an unbounded log or deletes made by anything but the retention pass and the owner's thread deletion.
