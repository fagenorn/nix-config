# ADR-release-007 — A deploy watch is a watch-only activation unit of a release profile

A deploy the publication triggers on its own was watched by a separate `bindings.deploy` and `capabilities.deploy` that could not be tied to the commit the release published. So project schema 2 has no `bindings.deploy`: a deploy watch is a `publication_triggered` activation unit of a release profile, served by `github-actions-health` and `railway-deploy`, which refuse every `invoke` with `unsupported_operation` and answer `running_subject_identity`, so the driver only inspects it. The candidate's `merge` binds into it, so it watches the release pull request's merge commit, and a deploy absent or running past its observation deadline parks rather than succeeds. Rejected: the separate deploy binding beside the release.
