# ADR-release-003 — A release profile is judged by grammar inside resolve and by admissibility apart

`resolve-project resolve` runs in every workflow, while whether a profile can run depends on the core's compilers and on which adapter executables a host has. So the grammar (`release_profile.grammar_violations`) runs inside resolve and reads only the authored document and the registered descriptors: every violation is `invalid_contract` with a `contract.release.*` repair, and an unknown adapter or unsupported operation is a grammar violation, never a lookup fallback. Admissibility (`release_profile.admissibility_findings`) runs over a grammar-valid profile only and feeds `capabilities.release`, so the capability and the inspection agree. Rejected: judging both inside resolve, which makes every resolve depend on the host and the core.
