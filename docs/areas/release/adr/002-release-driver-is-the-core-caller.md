# ADR-release-002 — The release driver is the transaction core's only caller

The transaction core (closed schema, fenced custody, write-intent protocol, proof and recovery plans, terminal receipts) was built for two consumers, the agent attempt lifecycle first and ship-release second, so that neither fixed its shape alone; the attempt lifecycle was later retired, which left one caller. The core stays whole as the release driver's store: the driver is its only caller, the core has no command of its own, and a change to the core is judged against the driver alone, with no compatibility promise beyond it. Rejected: cutting the core down to what the driver uses today, which loses the generality it was built with, and giving the core a command or a caller of its own.
