# ADR-project-contract-008 — A contract names the command its adoption commit runs through

A fresh adoption worktree lacks the generated, untracked hook configuration a project's development environment creates, so a project whose commit hooks need it failed at Apply. The contract names, in `bindings.vcs.commit.environment`, a command the adoption commit runs through: git commit is that command's trailing argv, in its cwd inside the worktree, with the trace file that names a failing hook set for git alone, and a leash ends the whole process tree when apply returns, times out or is killed. Only `adopt-project apply` reads the member; `adopt-project plan --commit-environment` adds it to a contract that names none, and schema 3 makes it a platform constant a drafted contract never authors. A failing environment or hook is retained as a failed commit, never retried without the environment and never run with hooks skipped. Rejected: running the command first and then a bare commit, which still fails a hook that needs the environment's variables or tools; skipping hooks; and a plain subprocess timeout, which kills only the launcher and leaves git free to move the branch.
