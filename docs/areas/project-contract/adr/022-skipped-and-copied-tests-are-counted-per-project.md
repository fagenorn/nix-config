# ADR-project-contract-022 — Skipped tests and copied test bodies are counted per project

B23 (skipped tests) and B24 (copied test bodies) are count rules of the never-rise check under ADR-project-contract-017: each fails when the project's total rises against the merge base, wherever a violation moves to, and each has its own enforcer and command (#1464, per #1421 and #1412). One reader of test declarations serves both: a test file is chosen by its stack's rules and read as tokens with comments and whitespace dropped, so a marker or a body is never read from a comment or a string. A skipped or disabled test is one violation at its line however many markers mark it; a marker on a suite header marks each test inside, a JavaScript declaration with no callback is skipped, a focusing marker counts, an expected failure does not, and a marker that marks no test counts once, except a C# attribute on anything but a test or a suite. Two tests are copies when their file family and body tokens are equal, the name, decorators, parameters and title never telling them apart: of n tests sharing a body, ordered by path and line, the first is kept and each other is a violation. Rejected: one violation per marker, which hides a test added under a skipped suite, and an assertion-count heuristic, which issue 1464 found mostly false positives. Known limit: a skip decided at run time or by a framework's own configuration is not counted.
