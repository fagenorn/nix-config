# ADR-guard-001 — Detaching words are refused in the raw text, before any policy loads

Context: `nohup`, `setsid` and `disown` start work that outlives the tool call, while `run_in_background: true` starts it tracked. Decision: the three words are refused in every repository before the policy loads, a word counting as a whole word in the raw text or in the copy with the gluing characters deleted (issue 656); only a `grep` or `rg` pattern and a quoted `gh issue|pr create|comment` title or body are admitted, and a mere mention is refused. Rejected: parsing shell syntax for the words, which quoting, brace expansion and parameter defaults slipped past.
