# ADR-guard-002 — A git invocation that could transmit refs is refused as a push

Context: git reaches a remote through aliases, `git-<name>` programs, transports and `-c` or environment values that git runs, and knowing an alias needs git configuration, which a session can write. Decision: a git invocation that could transmit refs and is no admitted lifecycle form is refused as a push, by closed tables (global options, local subcommands, value-running options, leading assignments) at every position, never reading git configuration; clearing `CLAUDECODE` and `git config core.hooksPath` are refused to protect the pre-push hook (ADR-guard-004). Rejected: an open list of dangerous words or reading git configuration, which a new subcommand, option or written config slips past; mentions such as `rg -n git` are refused as the price.
