# ADR-guard-007 — A derived row is re-derived at use before the guard relies on it

Context: a row compiled at activation sits in a writable file, and the registry, contract and remote change after the compile. Decision: for a repository with a row the guard re-derives that row at use with the compiler's own proof and relies on it only when `origin/HEAD`, the outcome, the branches and the required checks agree, on every repository-bound verb, nix-config included, with no fallback to an owner literal; the check is bounded inside the invocation deadline, and an unreachable `origin` or provider refuses; production rules are outside the comparison (ADR-guard-009). Rejected: trusting the stored row or a ref already present, which lets a stale or forged row authorize; the cost is seconds per verb.
