# ADR-guard-008 — Both merge arms keep the required-check floor

Context: a merge puts code on the default branch, so the guard demands protection with required checks, and a plan that cannot protect the branch and the release core's own merges pressed on that demand (issue 116, the guard/core decision). Decision: the floor holds for both merge arms and no core grant overrides the guard, host or provider verdict; the plan-gated floor (issue 552) replaces the protection demand only for the forge's 403 plan answer and only for a confirmed row that declares required checks; the release core's forge `pr_merge` is admitted under issue 554 only with strict required checks and admin enforcement, and any other core admission still waits; the mergeability check (issue 476) comes first. Rejected: letting a plan without protection or a core grant lower the floor, so a repository that can neither protect nor declare checks cannot merge through the guard.
