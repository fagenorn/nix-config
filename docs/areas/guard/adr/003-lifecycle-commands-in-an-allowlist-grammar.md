# ADR-guard-003 — A lifecycle command is admitted only in one allowlist grammar

Context: a lifecycle verb inside a larger command can run beside something the guard never judged. Decision: once a verb is found the command is admitted only as `[unset GITHUB_TOKEN && ][cd <dir> && ]<verb> <args>` with plain or quoted words and no expansion, judged before anything else, the only directory change being an absolute `cd` without `..`; anything else is refused with the accepted forms, and an adjudicated verb is never handed back to the allow list (issue 418). Rejected: judging each compound shape (a second segment, a redirection, an expansion, a wrapper) on its own, a list that grows with every shell feature.
