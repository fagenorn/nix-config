# ADR-guard-004 — A global pre-push hook judges the refs git actually pushes

Context: the text guard depends on recognising each spelling of a push, while git knows the real push URL and refs. Decision: the guard's second mode, `--mode pre-push`, runs as a global `core.hooksPath` hook on every host, judges git's facts with the text mode's predicates and policies, only in an agent session (non-empty `CLAUDECODE`), and chains to the repository's own `pre-push` and to git-lfs because a global hooks path disables per-repository hooks (issue 672). It catches mistaken spellings; branch protection and the required checks stop a deliberate bypass. Rejected: leaving the text guard the only judge, whose coverage ends at the spellings it recognises.
